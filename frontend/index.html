Eight specialised agents

Each agent does one job well.

No single model tries to do everything. Every agent reports a verdict, a confidence, and how much evidence backs it — the Context Gate decides how much each one should count.

AGENT 1

OCR & Structuring

Reads the uploaded invoice and extracts vendor, line items, amounts and GST into structured data.

AGENT 2

Semantic Matching

Compares the invoice against the goods actually received — not just the original order — to handle real partial deliveries fairly.

AGENT 3

Compliance

Independently recalculates the GST that should apply as of today's rate, rather than trusting a stale estimate.

AGENT 4

Fraud Detection

Watches for shared bank accounts between "different" vendors and invoices split to dodge an approval threshold.

AGENT 5

Vendor Risk Scoring

A running, evidence-weighted track record per vendor, per company — never borrowed from another company's experience.

AGENT 6

Quotation Ranking

Weighs price, delivery fit and proven history — a new vendor's thin record never gets treated as if it were reliable data.

AGENT 7

Vendor Communication

Drafts a factual, non-accusatory message the moment something needs clarifying — a human reviews before it ever sends.

AGENT 8

Decision Engine

The Context Gate itself — fuses every signal above into one final score and a plain-English reason for it.

The actual novel contribution

Confidence times evidence, nothing hidden.

Every agent's opinion is weighed by how sure it is and how much history backs it up — a shaky OCR read on a blurry scan gets discounted automatically; a vendor's genuine 50-invoice track record does not.

raw_weight_i = confidence_i × log(1 + data_volume_i) gate_weight_i = raw_weight_i / Σ(raw_weight_all_agents) final_score = Σ(gate_weight_i × agent_verdict_score_i)

A worked example: a blurry-scan invoice from a new vendor gets Matching's shaky signal automatically down-weighted, while a confident Fraud check and a valid GST result dominate the decision instead — so a clean transaction with a poor scan isn't wrongly flagged.
